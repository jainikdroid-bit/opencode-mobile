# インストールガイド

**言語：** [English](INSTALL.md) · [Русский](INSTALL.ru.md) · [中文](INSTALL.zh-Hans.md) · [Español](INSTALL.es.md) · [Deutsch](INSTALL.de.md) · [Français](INSTALL.fr.md) · [Português](INSTALL.pt.md) · 日本語 · [한국어](INSTALL.ko.md) · [Українська](INSTALL.uk.md) · [Türkçe](INSTALL.tr.md)

OpenCode Mobile は、**あなた自身のパソコン**で動いているコーディングエージェントを操作する Android アプリです。
セットアップは約 2 分、3 ステップで終わります。私たちのクラウドサービスは一切経由しません。スマートフォンは
プライベート接続でパソコンと直接通信します。

## 必要なもの

- **Android スマートフォン**（Android 7 以降）。
- **パソコン**：Windows 10/11、macOS、または Linux。電源が入っていてオンラインであること。
- 無料の **Tailscale** アカウント（Google、Microsoft、GitHub でログイン可能）。スマートフォンとパソコンをつなぐ
  プライベートな経路です。使いたくない場合は[その他の接続方法](#その他の接続方法)をご覧ください。

## ステップ 1：パソコンでコマンドを 1 つ貼り付ける

**Windows。** **PowerShell** を開き（スタートメニューで `PowerShell` と入力）、次を貼り付けます。

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.ps1)))
```

**macOS または Linux。** **ターミナル**を開き、次を貼り付けます。

```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.sh | sh
```

スクリプトは作業しながら各ステップを説明します。

1. 足りないものをインストールします（Node.js、opencode）。Windows が許可を求めたら**はい**を押します。
2. **Tailscale** をインストールし、ログインページを開きます。Google、Microsoft、GitHub のいずれかを選びます。必要なアカウントはこれだけです。
3. サーバーを起動し、**2 つの QR コード**（アプリ用とペアリング用）があるページを開きます。

このコマンドはいつでも安全に再実行できます。重複させず、修復します。

## ステップ 2：スマートフォンにアプリをインストールする

1. **1 つ目**の QR コードを読み取るか、[リリースページ](https://github.com/jainikdroid-bit/opencode-mobile/releases/latest)を開いて
   `OpenCode-Mobile-<バージョン>.apk` をダウンロードして開きます。Android がブラウザからのインストールを一度だけ確認してくるので、許可してください。
2. Google Play から **Tailscale** をインストールし、パソコンと**同じアカウント**でログインします。

## ステップ 3：スマートフォンで接続する

アプリを開いて**QR をスキャンしてペアリング**をタップし、**2 つ目**の QR コードにカメラを向けて**接続**をタップします。完了です。

初回はアプリが短いセットアップガイドを表示します。**ガイドをスキップ**をタップすると二度と表示されません。

## セットアップ後

- **普段の使い方：**アプリを開くだけです。小さな非表示のヘルパー（*ランチャー*）がパソコンと一緒に起動し、サーバーを立ち上げます。
  サーバーが止まっているときは、アプリに**開始**ボタンが表示されます。パソコンは電源が入っていてオンラインである必要があります。
  スリープ中のパソコンを起こすことはできません。
- **確認または修復：**同じコマンドをもう一度実行するか、`-Doctor`（確認のみ）/ `-Stop`（サーバー停止）を付けます。
- **すべて削除：**`-Uninstall` を付けます。設定は削除できるフォルダーに残ります（場所はスクリプトが表示します）。

オプションはコマンドの後ろに付けます。Windows では `-Doctor`、macOS/Linux では `sh -s --` の後に `--doctor` のように書きます。
`curl -fsSL <url> | sh -s -- --doctor`

## その他の接続方法

| 状況 | 付けるオプション | 動作 |
|---|---|---|
| スマートフォンとパソコンが同じ Wi-Fi で、Tailscale は使いたくない | `-Mode lan`（`--mode lan`） | 自宅ネットワーク内だけで接続可能。アカウント不要 |
| スマートフォンに VPN がない | `-Mode tunnel`（`--mode tunnel`） | 無料の Cloudflare トンネル。下の注意を参照 |
| 説明を省略 | `-NoGuide`（`--no-guide`） | 静かな出力 |
| サインイン時にヘルパーを起動しない | `-NoAutostart`（`--no-autostart`） | コマンドを実行したときだけサーバーが起動 |

### トンネルモードについて、正直に

`-Mode tunnel` は無料の `cloudflared` クライアントをダウンロードし、外向きのみの Cloudflare トンネルを開きます（アカウント不要、
ポート開放不要）。このアドレスは**公開インターネット上**にあり、長いランダムなパスワードと推測できないアドレスで保護されています。
同じクライアントから 10 回間違えると 1 分間ブロックされます。トンネルを再起動するとアドレスが変わりますが、アプリが自動で新しいアドレスを取得します。
ペアリングリンクを入手した人は誰でもエージェントを使えるので、決して共有しないでください。引き続き Tailscale を推奨します。

## 便利な機能

- **OpenCode に共有：**任意のアプリで共有を押して OpenCode を選ぶと、テキスト、リンク、画像、小さなテキストファイルがセッションに入ります。
- **音声会話：**マイクの横のヘッドセットをタップして話すと、返答が読み上げられ、再び聞き取りを始めます。
- **クイック許可：**エージェントが何かの実行を求めると、バナー（と通知）に 拒否 / 常に / 許可 が表示されます。
- **セッションの検索と固定：**セッション画面の検索ボックス。セッションを長押しすると固定できます。
- **エージェント用スマートフォン機能（任意、初期状態はオフ）：**インストーラーを `-PhoneTools`（`--phone-tools`）付きで実行し、
  アプリで*設定 → AI エージェント用スマートフォン機能*をオンにします。エージェントは通知の表示、読み上げ、クリップボードの利用、
  位置情報の取得、写真の撮影依頼ができます。重要な操作は毎回確認され、アプリを開いている間だけ動作します。

## トラブルシューティング

| 問題 | 対処 |
|---|---|
| アプリが接続できない | スマートフォンとパソコンは**同じ** Tailscale アカウントを使う必要があります。スマートフォンの Tailscale を開き、オンになっているか確認してください。 |
| コマンドを貼り付けても何も開かない | `-NoOpen` を付けて再実行し、ページの代わりに表示されるペアリングリンクを使います。 |
| 「スクリプトの実行が無効になっています」 | コマンドを表示どおりに貼り付けてください（スクリプトの許可は不要です）。`.ps1` ファイルとして保存しないでください。 |
| カメラが QR コードを読み取らない | アプリ内の**QR をスキャンしてペアリング**を使うか、表示されたリンクを**接続を追加 → ペアリングリンクを貼り付け**にコピーします。 |
| ペアリングリンクが拒否される | パスワードが変更された（`-Rotate`）か、リンクが途中で切れています。コマンドを再実行して新しいリンクを使ってください。 |
| サーバーが止まっていてスマートフォンから起動できない | パソコンがスリープ中かオフライン、またはヘルパーが削除されています。パソコンを起動するか、コマンドを再実行してください。 |

## 対応プラットフォーム

| | パソコン | スマートフォン |
|---|---|---|
| Windows 10/11 | テスト済み | 該当なし |
| Linux | 対応（systemd または XDG 自動起動）、テストは限定的 | 該当なし |
| macOS | 対応（LaunchAgent）、実機ではまだ未テスト | 該当なし |
| Android | 該当なし | テスト済み |
| iOS | 該当なし | コードは互換ですが、iOS 向けビルドは未作成・未テスト |

Нативный клиент Android для агента [opencode](https://github.com/sst/opencode). Он общается только с сервером, который запускаете **вы**, по вашей собственной сети. Никаких ретрансляторов и облачных сервисов.

> Независимый клиент сообщества; не связан с командой opencode.

## Возможности

**Видно, что делает агент.** Живая полоса активности называет этап («Агент думает», «Использует bash», «Пишет ответ») и ведёт таймер; блок рассуждений сворачивается в «Думал 0:12».

**Сопряжение одним сканированием.** Запустите на компьютере один скрипт, наведите камеру на QR-код, подтвердите. Сервер остаётся на `127.0.0.1` и публикуется только внутри вашей сети Tailscale.

**Модель на выбор: локальная или облачная.** Фильтр «Все / Локальные / Облачные»; модели с вашего компьютера помечены, переключение — одно касание.

**Запуск сервера с телефона.** Если сервер на компьютере выключен, приложение покажет кнопку «Запустить».

**Отвечайте агенту откуда угодно.** Просьба агента о разрешении появляется баннером на любом экране; в уведомлении те же кнопки.

**Голосовой диалог.** Нажмите на гарнитуру: говорите, слушайте ответ, и приложение снова слушает.

**«Поделиться» в OpenCode, поиск и закрепление сессий.**

**Терминал, файлы, MCP-коннекторы,** диффы, вложения-изображения, несколько серверов, биометрическая блокировка, ключи в Android Keystore.

## Установка в три шага (около двух минут)

**[Полное руководство с решением проблем](../INSTALL.ru.md)**

**1. Компьютер: вставьте одну команду.** В PowerShell (Windows):

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.ps1)))
```

macOS / Linux, в Терминале:

```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.sh | sh
```

Команда ставит недостающее (Node.js, opencode, Tailscale), один раз просит войти в Tailscale, запускает сервер и открывает страницу с двумя QR-кодами.

**2. Телефон: установите.** Отсканируйте первый QR-код (или откройте [Releases](https://github.com/jainikdroid-bit/opencode-mobile/releases/latest)), скачайте APK и откройте его. Установите Tailscale и войдите в тот же аккаунт.

**3. Телефон: подключитесь.** Откройте приложение, нажмите **Сканировать QR для подключения**, наведите на второй QR-код, нажмите **Подключиться**.

Команду можно запускать повторно (она чинит, а не дублирует). Не нужен Tailscale? `-Mode lan` (одна Wi-Fi сеть) или `-Mode tunnel` (бесплатный туннель Cloudflare; компромиссы — в руководстве).

## Приватность

Без аналитики, без отчётов о сбоях, без аккаунтов. Приложение общается только с добавленными вами серверами. Единственный другой запрос — необязательная раз в сутки проверка релизов этого проекта на GitHub. Учётные данные хранятся в Android Keystore.

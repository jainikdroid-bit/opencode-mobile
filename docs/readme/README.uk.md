Нативний клієнт Android для агента [opencode](https://github.com/sst/opencode). Він спілкується лише із сервером, який запускаєте **ви**, у вашій власній мережі. Жодних ретрансляторів чи хмарних сервісів.

> Незалежний клієнт спільноти; не пов'язаний із командою opencode.

## Можливості

**Видно, що робить агент.** Жива смуга активності називає етап («Агент думає», «Використовує bash», «Пише відповідь») і веде таймер; блок міркувань згортається в «Думав 0:12».

**З'єднання одним скануванням.** Запустіть на комп'ютері один скрипт, наведіть камеру на QR-код, підтвердьте. Сервер лишається на `127.0.0.1` і публікується лише у вашій мережі Tailscale.

**Модель на вибір: локальна чи хмарна.** Фільтр «Усі / Локальні / Хмарні»; моделі з вашого комп'ютера позначено, перемикання — одне торкання.

**Запуск сервера з телефона.** Якщо сервер на комп'ютері вимкнено, застосунок покаже кнопку «Запустити».

**Відповідайте агентові звідусіль.** Коли він просить дозвіл, на будь-якому екрані з'являється банер; у сповіщенні ті самі кнопки.

**Голосова розмова.** Торкніться гарнітури: говоріть, слухайте відповідь, і застосунок знову слухає.

**«Поділитися» з OpenCode, пошук і закріплення сесій.**

**Термінал, файли, MCP-конектори,** різниці, вкладення-зображення, кілька серверів, біометричне блокування, облікові дані в Android Keystore.

## Встановлення за три кроки (близько двох хвилин)

**[Повний посібник із розв'язанням проблем](../INSTALL.uk.md)**

**1. Комп'ютер: вставте одну команду.** У PowerShell (Windows):

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.ps1)))
```

macOS / Linux, у Терміналі:

```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.sh | sh
```

Вона встановлює відсутнє (Node.js, opencode, Tailscale), один раз просить увійти в Tailscale, запускає сервер і відкриває сторінку з двома QR-кодами.

**2. Телефон: встановіть.** Відскануйте перший QR-код (або відкрийте [Releases](https://github.com/jainikdroid-bit/opencode-mobile/releases/latest)), завантажте APK і відкрийте його. Встановіть також Tailscale й увійдіть у той самий обліковий запис.

**3. Телефон: підключіться.** Відкрийте застосунок, торкніться **Сканувати QR для сполучення**, наведіть на другий QR-код, торкніться **Підключитися**.

Повторний запуск команди безпечний (вона лагодить, а не дублює). Не потрібен Tailscale? `-Mode lan` (одна Wi-Fi мережа) або `-Mode tunnel` (безкоштовний тунель Cloudflare; компроміси — у посібнику).

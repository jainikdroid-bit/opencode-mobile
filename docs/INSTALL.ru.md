# Руководство по установке

**Языки:** [English](INSTALL.md) · Русский · [中文](INSTALL.zh-Hans.md) · [Español](INSTALL.es.md) · [Deutsch](INSTALL.de.md) · [Français](INSTALL.fr.md) · [Português](INSTALL.pt.md) · [日本語](INSTALL.ja.md) · [한국어](INSTALL.ko.md) · [Українська](INSTALL.uk.md) · [Türkçe](INSTALL.tr.md)

AgentLink — приложение для Android, которым вы управляете агентом, работающим на **вашем собственном компьютере**.
Настройка занимает около двух минут и три шага. Никаких наших облачных сервисов: телефон общается с компьютером по
частному соединению.

## Что понадобится

- **Телефон на Android** (Android 7 или новее).
- **Компьютер** с Windows 10/11, macOS или Linux, включённый и с доступом в интернет.
- Бесплатная учётная запись **Tailscale** (вход через Google, Microsoft или GitHub). Это частный канал между телефоном и
  компьютером. Не хотите? См. [другие способы подключения](#другие-способы-подключения).

## Шаг 1. На компьютере: вставьте одну команду

**Windows.** Откройте **PowerShell** (меню «Пуск», наберите `PowerShell`) и вставьте:

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.ps1)))
```

**macOS или Linux.** Откройте **Терминал** и вставьте:

```sh
curl -fsSL https://raw.githubusercontent.com/jainikdroid-bit/opencode-mobile/main/tools/opencode-connect.sh | sh
```

Скрипт объясняет каждый шаг по ходу работы:

1. Ставит недостающее (Node.js, opencode). Если Windows попросит разрешение, нажмите **Да**.
2. Ставит **Tailscale** и открывает страницу входа. Выберите Google, Microsoft или GitHub. Это единственная учётная запись,
   которая вам нужна.
3. Запускает сервер и открывает страницу с **двумя QR-кодами** (один для приложения, другой для сопряжения).

Команду можно безопасно запускать повторно в любой момент: она чинит, а не дублирует.

## Шаг 2. На телефоне: установите приложение

1. Отсканируйте **первый** QR-код или откройте [страницу релизов](https://github.com/jainikdroid-bit/opencode-mobile/releases/latest),
   скачайте `OpenCode-Mobile-<версия>.apk` и откройте его. Android один раз спросит разрешение на установку из браузера:
   разрешите.
2. Установите **Tailscale** из Google Play и войдите в **ту же учётную запись**, что и на компьютере.

## Шаг 3. На телефоне: подключитесь

Откройте приложение, нажмите **Сканировать QR для подключения**, наведите камеру на **второй** QR-код и нажмите
**Подключиться**. Готово.

**Не получается отсканировать?** Нажмите **Подключить по коду**. Команда установки показывает рядом с QR-кодом 6 цифр:
приложение само находит компьютер, вы вводите цифры. Код действует один раз, 10 минут; для нового запустите команду ещё раз.

**Дома без Tailscale и VPN.** Компьютер отвечает и по адресу домашней сети, и приложение идёт туда напрямую, когда телефон
в том же Wi-Fi (сначала проверяет, что это именно ваш компьютер). Вне дома — как раньше, через Tailscale. Если Windows
спросит, можно ли Node.js пользоваться сетью, разрешите частные сети. Отключить: `--no-lan`.

**Другие агенты для кода.** Кроме OpenCode, приложение умеет общаться с Claude Code, Codex, Gemini CLI, Goose, Qwen Code и
GitHub Copilot CLI, установленными на компьютере, через открытый протокол Agent Client Protocol. На вкладке «Сеансы» нажмите
**Другие агенты**, выберите агента и запустите. Он работает со своим входом и инструментами на компьютере; телефон показывает
ответы, план, вызовы инструментов и правки файлов и спрашивает вас перед действиями агента. Агент продолжает работать, когда
вы выходите с экрана, и его можно открыть снова из того же списка. После обновления приложения нужно ещё раз запустить команду установки.

При первом запуске приложение покажет короткий гид по настройке; нажмите **Пропустить гид**, и он больше не появится.

## После настройки

- **Каждый день:** просто откройте приложение. Маленький скрытый помощник (*пускатель*) стартует вместе с компьютером и
  поднимает сервер. Если сервер выключен, в приложении появится кнопка **Запустить**. Компьютер должен быть включён и в сети:
  разбудить спящий компьютер нельзя.
- **Проверить или починить:** запустите ту же команду ещё раз либо добавьте `-Doctor` (только проверка) / `-Stop` (остановить сервер).
- **Убрать всё:** добавьте `-Uninstall`. Ваши настройки остаются в папке, которую можно удалить (скрипт покажет, где она).

Флаги пишутся после команды. В Windows — как `-Doctor`; в macOS/Linux — как `--doctor` после `sh -s --`:
`curl -fsSL <url> | sh -s -- --doctor`.

## Другие способы подключения

| Ситуация | Добавьте флаг | Что делает |
|---|---|---|
| Телефон и компьютер в одной Wi-Fi сети, Tailscale не нужен | `-Mode lan` (`--mode lan`) | Доступ только из домашней сети, никаких аккаунтов |
| На телефоне нет VPN | `-Mode tunnel` (`--mode tunnel`) | Бесплатный туннель Cloudflare, см. предупреждение ниже |
| Без пояснений | `-NoGuide` (`--no-guide`) | Тихий вывод |
| Не запускать помощника при входе в систему | `-NoAutostart` (`--no-autostart`) | Сервер стартует только когда вы запускаете команду |

### Режим туннеля: честно о компромиссе

`-Mode tunnel` скачивает бесплатный клиент `cloudflared` и открывает исходящий туннель Cloudflare (без аккаунта, без
открытых портов). Адрес **доступен в интернете**; его защищают длинный случайный пароль и неугадываемый адрес, а неверные
попытки с одного клиента блокируются на минуту после 10 попыток. Адрес меняется при перезапуске туннеля, приложение само
узнаёт новый. Любой, кто получит вашу ссылку сопряжения, сможет пользоваться агентом, поэтому никому её не показывайте.
По умолчанию рекомендуется Tailscale.

## Удобные возможности

- **«Поделиться» в OpenCode:** в любом приложении нажмите «Поделиться» и выберите OpenCode; текст, ссылки, изображения и
  небольшие текстовые файлы попадут в сессию.
- **Голосовой диалог:** нажмите на гарнитуру рядом с микрофоном, говорите, слушайте ответ, и приложение снова слушает.
- **Быстрые разрешения:** когда агент просит что-то выполнить, баннер (и уведомление) предлагает Отклонить / Всегда / Разрешить.
- **Поиск и закрепление сессий:** поле поиска на экране сессий; долгое нажатие на сессию закрепляет её.
- **Функции телефона для агента (по желанию, по умолчанию выключено):** запустите установщик с `-PhoneTools`
  (`--phone-tools`), затем включите *Настройки → Функции телефона для ИИ-агента*. Агент сможет показывать уведомления, говорить
  вслух, пользоваться буфером обмена, узнавать местоположение или просить вас сделать фото. Чувствительные действия
  спрашивают каждый раз, работает только при открытом приложении.

## Пусть всё сделает ИИ-агент

Скажите своему агенту (Claude Code, opencode, Codex, ...):

> Настрой для меня AgentLink. Следуй https://github.com/jainikdroid-bit/opencode-mobile/blob/main/docs/AI-SETUP.md

От вас потребуется только нажать **Да** в окне Windows, один раз войти в Tailscale и нажать **Подключиться** на телефоне.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Приложение не подключается | Телефон и компьютер должны использовать **одну и ту же** учётную запись Tailscale. Откройте Tailscale на телефоне и проверьте, что он включён. |
| После вставки команды ничего не открылось | Запустите её с `-NoOpen` и используйте ссылку сопряжения, которую она напечатает, вместо страницы. |
| «Выполнение сценариев отключено» | Вставьте команду точно как показано (ей не нужно разрешение на сценарии); не сохраняйте её в файл `.ps1`. |
| Камера не видит QR-код | Используйте «Сканировать QR для подключения» в самом приложении или скопируйте напечатанную ссылку в **Добавить подключение → Вставить ссылку сопряжения**. |
| Ссылка сопряжения отклонена | Пароль сменили (`-Rotate`) или ссылка обрезана. Запустите команду заново и используйте новую ссылку. |
| Сервер выключен, и телефон не может его запустить | Компьютер спит или без сети, либо помощник удалён. Включите компьютер или запустите команду заново. |
